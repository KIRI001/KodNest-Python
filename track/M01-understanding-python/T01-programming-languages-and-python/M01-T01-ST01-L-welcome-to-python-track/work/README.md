# Programming vs Programming Language

## What Is Programming?

Programming is the process of giving instructions to a computer to perform a specific task or solve a problem. It helps us create software, websites, applications and games.


## What Is a Programming Language?

A programming language is a language that we use to communicate with a computer. It allows us to write instructions that a computer can understand and execute.


## What Is Python?

Python is a high-level, interpreted programming language. It has simple and readable syntax, which makes it easy to learn and use. It is used in web development, automation, artificial intelligence, data science and many other fields.

## What Is Syntax?

Syntax refers to the rules and structure we must follow while writing code in a programming language. If we don't follow the correct syntax, our program may show an error.

## Programming and Python

Programming is the process of creating instructions to solve problems, whereas Python is a programming language used to write those instructions.

Example:
- Programming is the process of preparing a recipe.
- Python is the language we use to write that recipe.


## What Remained the Same?

The basic logic and steps of solving the problem remained the same. Only the way we wrote the instructions changed when converting pseudocode into Python.

## What Changed?

When pseudocode was converted into Python, the simple English-like instructions were replaced with actual Python syntax.
